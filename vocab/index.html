単語の管理

単語の追加・編集・削除はここから。保存できるのはGitHubトークンを登録した端末だけです。

GitHub接続

保存にはGitHubのアクセストークンが必要です。トークンはこの端末のブラウザにだけ保存されます。

トークンの作り方
  1. GitHubにログインし、右上のアイコン →「Settings」→ 左メニュー一番下の「Developer settings」
  2. 「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
  3. Token name は自由（例: vocab）。Expiration（有効期限）を選ぶ
  4. Repository access で「Only select repositories」→ を選ぶ
  5. Permissions の「Contents」を「Read and write」にする
  6. 「Generate token」を押し、表示された github_pat_… をコピーして下に貼る

● この端末は接続済みです。保存すると全員の画面に反映されます。
