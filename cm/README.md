# 受験勉強 運行表 CM（横長 1920x1080・43秒）

- `cm_juken_unkohyo_gemini.mp4` … 完成動画（ナレーション：Gemini TTS `gemini-3.8-flash-tts` / ボイス `Kore`）
- `narration_gemini.mp3` … ナレーション音声のみ（約30秒・7シーン分を通しで読み上げ）

## 台本（7シーン）

| # | 時間 | ナレーション |
|---|------|--------------|
| 1 | 0:00–0:05.5 | 勉強の1日を、電車のダイヤのように。 |
| 2 | 0:05.5–0:12 | 科目と時間を入れるだけで、時刻表が完成。 |
| 3 | 0:12–0:17.5 | 予定とのズレが、ひと目でわかる。 |
| 4 | 0:17.5–0:23 | 就寝時間も、しっかり守れる。 |
| 5 | 0:23–0:28 | ポモドーロタイマー内蔵。 |
| 6 | 0:28–0:34.5 | スマホでも、パソコンでも。どこでも使える。 |
| 7 | 0:34.5–0:43 | 今日の勉強を、最後まで走り切ろう。受験勉強、運行表。 |

## 作り直し手順（`src/`）

1. `GEMINI_API_KEY=... python3 tts2.py gemini-3.8-flash-tts Kore full_kore.wav` … ナレーション生成
2. `python3 shots.py` … サンプルデータ入りのアプリ画面を撮影（Playwright）
3. `python3 render.py` … `scene.html` から 7 シーンの静止画を書き出し
4. `python3 build.py` … 音声をシーンごとに切り分け、ズーム＋クロスフェードで動画化

声を変える場合は `tts2.py` の第2引数（例: `Aoede`, `Leda`, `Puck`）を変え、`build.py` の `cuts`（文の区切り秒）を無音位置に合わせて調整します。
